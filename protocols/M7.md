# M7 — complex tasks (registered 2026-11-05, before the first run)

**Question.** At equal accuracy, what does it cost the agent to reach the delivered total?

**Tasks.**
- C1, store B: four identical pillows (some models can be ordered at most 2 at a time) and a double mattress 160x190 cm.
- C2, store B: two different pillows, budget close to the free-shipping threshold (shipping is free only above a given amount of goods).
- C3, store A: a named bralette in a size that does not exist; the closest size (same band or same cup) is accepted; plus a brief in size 3.
- C4, stores A and B: one brief on store A and one pillow on store B, two separate orders, one budget for both.

**Runs.** 20 per arm (5 per task), one at a time, 120 s between runs, Retry-After passed to the agent. Model `deepseek-flash`, default temperature. KaliCart Bridge 1.0.160 on both stores.

**Thresholds** (set before the first run; an earlier draft asked K to be more accurate than S, and was changed before any M7 run to make tokens the primary measure and accuracy a non-inferiority check).
- C (primary). Median tokens per run of K <= 60% of S.
- A'. Accuracy not worse: verified K >= verified S - 1.
- B (secondary). Median calls of K <= 60% of S.

**Verdict.**
- C: yes. Median 215k vs 698k tokens, 69% fewer (C1 63%, C2 69%, C3 67%, C4 76%).
- A': yes. 20/20 vs 17/20 (S: one run over budget, two correct totals computed by the agent instead of read from the store).
- B: no. Median 10 vs 14 calls, 29% fewer.
- Descriptive: time 39 s vs 81 s; failed calls 4 vs 26; no 429. Real model credit for the 40 runs: $1.31, split by tokens about $0.015 per K run and $0.051 per S run (about $15 vs $51 per 1,000 purchases).
